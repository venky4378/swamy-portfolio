# Venkayya Swamy Chamanthi - Developer Portfolio

A modern, high-performance developer portfolio built with **React 19, Vite, Tailwind CSS**, and an executive dark aesthetic.

Live URL: *(Deploy to Vercel or GitHub Pages)*

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

## 📦 Production Build

```bash
npm run build
```

The output will be in the `dist/` directory, ready to deploy.

## 🌐 Deploy to Vercel (Recommended - 1 Click)

1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of developer portfolio"
   git branch -M main
   git remote add origin https://github.com/venky4378/portfolio.git
   git push -u origin main
   ```
2. Log in to [Vercel](https://vercel.com) with GitHub.
3. Click **Add New Project**, select `portfolio`, and click **Deploy**.
   *(The included `vercel.json` ensures full SPA routing support).*
